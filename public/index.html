自己部署并分析网站

适合懂浏览器开发者工具、HTTP 或 Playwright 的用户。

  1. 获得网站授权，用测试编号手动查询一次。
  2. 在 Network 的 Fetch/XHR 中找查询请求、下载接口和 JSON 返回值。
  3. 没有 API 时，检查搜索框、结果卡片和下载链接的 HTML 选择器。
  4. 实现 PortalAdapter，只返回 match_code 与 submissions。
  5. 把 Token 放环境变量，先跑测试与只读预检，再部署定时任务。
